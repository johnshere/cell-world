# Cell World

一个基于Python和Pygame的网格世界应用程序。

## 功能特点

- 1200*800的窗口，支持全屏模式
- 右侧400宽的面板，用于数据展示，支持展开和收起
- 10像素正方形网格，带有坐标系
- 支持鼠标拖拽移动坐标系，能够无限滚动
- 独立的配置文件，方便自定义设置

## 安装依赖

```
pip install -r requirements.txt
```

## 运行程序

本项目提供多种启动方式，选择其中一种即可：

### 1. 使用启动器（推荐）

```
./start.bat
```

或者：

```
python start.py
```

启动器提供图形界面，可以选择运行标准版本、优化版本或测试脚本。

### 2. PowerShell启动（Windows）

```
./start.ps1
```

### 3. 直接运行标准版本

```
./run.bat
```

或者：

```
python main.py
```

### 4. 直接运行优化版本

```
./run_optimized.bat
```

或者：

```
python main_optimized.py
```

## 操作说明

- 左键拖拽：移动坐标系
- F11：切换全屏模式
- ESC：退出全屏或退出程序
- 面板右侧按钮：展开/收起面板

## 配置文件

可以通过修改`config.py`文件来自定义应用程序的各种设置：

- 窗口设置：尺寸、标题、全屏模式等
- 面板设置：宽度、颜色、边框等
- 网格设置：单元格大小、线条颜色等
- 坐标系设置：轴颜色、标签大小等
