- 基因，调制神经元参数
  - 前位基因引用
  - 后位基因引用
  - 触发器
  - 执行器

  - 时长，sec，存活时长
  - 分区
  - 分层
  - 链表：基因组
  - In 突触组，树突连入

  - 神经元引用
  - IO 类型，输入输出，轴突树突

  - 连接目标组
  - 整流器

### 突触数据类型

- 第一种是 “脉冲频率”，0-255 整数，模拟神经元放电频率，适合传递强度类信息；
- 第二种是 “单次脉冲能量”，0-1 浮点数，代表单次信号释放的能量，可模拟神经递质释放量差异；
- 第三种是 “双向调制”，-1 到 1 有符号数，专门用于调节目标神经元的敏感度，正数增强、负数抑制；第四种是 “时序快照”，包含最近 5 次信号值的数组，能传递信号的变化趋势，比如从弱到强的预警过程；
- 第五种是 “阈值触发”，只有 0 和 1 两种状态，当输入信号达到临界值时触发，适合传递开关类的决策信号；
- 第六种是 “连接权重标识”，1-10 整数，代表当前信号在目标神经元输入中的优先级权重，数值越高越容易影响输出结果。

## 实现类

- 基因
  - 端点基因，固定的，触发起点
    - 位置组，归一化，值\*基因组长度确定指定基因位置
    - 触发器，输入生命时间、细胞时间、基因组、其他
    - 执行器，输入生命时间、细胞时间、基因组、其他。控住注入基因触发器注入，包括自己
  - 变异基因，控制繁殖生命时基因组变异复制
    - 触发器，繁殖
    - 执行器，负责基因组交换、变异
  - 分裂基因，调制分裂相关参数
    - 触发器，生命时间、细胞时间、分区、分层、其他
    - 执行器
  - 连接基因，调制突触相关参数
    - 触发器，输入生命时间、细胞时间、基因组、其他
    - 执行器
  - 转换基因，调制转换器相关参数
    - 触发器，无
    - 执行器
  - 分发基因
