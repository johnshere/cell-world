# Cell World 简化大版本方案

## 设计目标

简化系统复杂度，让温度成为核心生存压力，推动集群行为涌现。

---

## 一、删除鼻子

**原因**：鼻子与眼睛功能重叠，唯一独特能力（痕迹追踪）对前馈网络不可行——需要记忆、选择性注意和长时序规划，超出 NEAT 前馈网络能力。

**改动**：
- 删除鼻子感知通道（原 [0..4] 共5维）
- 删除鼻子渲染（canvas.rs 中的线段绘制）
- 删除配置项：nose_cooldown, nose_scan_cost, nose_half_angle
- 痕迹点保留为纯物理机制（移动消耗→痕迹能量→接触吸收），不再有感知通道

---

## 二、删除器官基因系统

**原因**：根据经验，器官开关随机变异对进化无意义。删除器官消耗后，功率基因也无权衡意义（没理由不拉满）。

**改动**：
- 删除 `OrganGenes` 结构体（nose/eyes/mouth 开关 + nose_power/eye_power/mouth_power）
- 双眼、嘴巴始终存在，无需基因控制
- 删除器官变异逻辑、器官交叉逻辑
- 眼睛探测距离固定 = `vision_range`
- 咬合力固定 = `|mouth_output|`
- 相似度计算中器官差异扣分全部删除
- 器官相关 UI 配置项删除

---

## 三、简化能量消耗

**保留**：
- 基础代谢（base_metabolism × age_multiplier）
- 移动消耗（move_cost × distance）
- 转向消耗（防止无意义旋转）
- 体温逸散（核心生存压力，见下节）

**删除**：
- 器官按需扣费（nose_scan_cost, eye_scan_cost）

---

## 四、重设温度系统（核心改动）

### 4.1 环境温度 = 火山热 + 集体热

```
env_temp(x, y) = volcano_temp(x, y) + group_temp(x, y)
```

- **火山热**：距火山三次方衰减（公式不变）
- **集体热**：以 (x,y) 为中心，vision_range 半径内所有生物能量总和，与环境温度正相关

集体热使生物聚集区域形成"暖区"，自然产生群居压力：独行者冷得快死得早，抱团者互相取暖存活率高。

### 4.2 体温逸散公式

```
heat_cost = coefficient × circumference / env_temp × dt
```

- 与体表周长成正比（大生物散热面积大）
- 与环境温度成反比（越冷逸散越快）
- 火山附近+集群中逸散低，远离+孤立逸散高

**删除**：
- last_warm_time / cold_duration 整套机制
- 吃东西回暖
- 被喂食回暖
- creature.rs 中的 last_warm_time 字段

### 4.3 温度感知

**双眼热感温度**：每只眼在其视锥范围内感知环境温度（火山+集体叠加场），随眼睛冷却同步扫描。

生物能"看到"：
- 火山方向更暖
- 有生物群聚的方向更暖
- 空旷寒冷区域

**自身环境温度**：当前位置的 env_temp，用于判断即时逸散压力。

---

## 五、统一距离参数

`vision_range` 同时控制：
- 眼睛探测距离（食物/同族/异族/温度）
- 集体温度判定半径

---

## 六、其他调整

- **战力公式**：warmth 参数改用当前位置 env_temp（替代已删除的 cold_duration）
- **眼睛冷却**：保留，时间减半（0.15s → 0.075s），用于性能节流
- **嘴巴冷却**：保留（1.0s），咬/喂仍受冷却限制，食物吸收不受限

---

## 七、新输入输出规格

### 输入（10维）

```
左眼 (4通道) [0..3]:
  [0] 能量粒子接近度（最近，1 - dist/vision_range）
  [1] 同族接近度
  [2] 异族接近度
  [3] 热感温度（视锥内环境温度）

右眼 (4通道) [4..7]:
  [4] 能量粒子接近度
  [5] 同族接近度
  [6] 异族接近度
  [7] 热感温度

自身 (2通道) [8..9]:
  [8] 能量（energy/200, clamp 0~1）
  [9] 当前位置环境温度（env_temp）
```

### 输出（6维，不变）

```
[0] 转向角      tanh(-1~1) → × 2π 每秒弧度
[1] 速度        tanh(-1~1) → abs × 50 每秒距离
[2] 嘴          tanh(-1~1) → <-0.1 咬, >+0.1 喂
[3] 繁殖意愿    tanh(-1~1) → >0.2 触发
[4] 繁殖阈值    tanh→sigmoid → 20~200 能量
[5] 子代能量比例 tanh→sigmoid → 0.1~0.5
```

## 九、预期效果

- **系统简化**：输入 14→10 维，删除器官基因系统和体温历史机制
- **温度驱动集群**：集体热效应使群居成为生存优势，推动族群行为涌现
- **方向感知**：双眼热感温度提供温度梯度方向，生物能主动寻暖
- **统一物理**：能量消耗逻辑清晰（移动+转向+逸散），温度公式统一（火山+集体）
