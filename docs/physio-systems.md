# 生理系统设计文档

> 隶属于 [DESIGN.md](DESIGN.md) 的子文档，专注于生理信号通道的设计与扩展规划。

## 概述

生理系统是神经学习的内驱动机制。世界在特定事件发生时向生物注入生理信号（`PhysioState`），信号经 `PhysioGene` 的通道敏感度加权后，通过 eligibility trace 反向调整神经权重。

每个通道相互独立，可单独启用、单独演化敏感度。

```
世界事件
  │
  ├─ 吃到食物 ──→ PhysioState.pleasure += ...
  ├─ 被咬    ──→ PhysioState.pain    += ...
  └─ ...

PhysioState（帧内缓冲）
  │  × PhysioGene（各通道敏感度，可演化）
  ▼
total_reward = Σ(通道值 × 敏感度)
  │
  ▼
eligibility_trace × total_reward × hebbian_sign × rate → Δw
```

## 已实现通道

### 快乐 (pleasure) ✅
- **类比**：多巴胺
- **触发**：吸收能量粒子 `+absorbed/initial_energy`、吸收痕迹点 `+absorbed/initial_energy`、成功繁殖 `+0.5`
- **驱动行为**：主动觅食、留在资源区、产生繁殖意愿

## 规划通道

### 代谢 / 能量维度

#### 饥饿 (hunger)
- **类比**：饥饿素（Ghrelin）
- **触发**：每帧能量低于某阈值时持续注入负信号，能量越低信号越强
- **信号**：负（punishment）
- **驱动行为**：低能量时主动觅食，避免消耗型行为

#### 饱腹 (satiety)
- **类比**：瘦素（Leptin）
- **触发**：能量高于某阈值时注入正信号
- **信号**：正
- **驱动行为**：停止过度摄食，转向繁殖或探索

#### 省力 (effort_saving)
- **类比**：运动后的轻松感
- **触发**：当帧实际移动消耗低于基线消耗（下坡、跟随、高速但省力路径）
- **信号**：正，差值越大信号越强
- **驱动行为**：偏好下坡路径、跟随族群（跟随时 slope_factor 趋于平均）、顺地形移动
- **备注**：现有物理层已有 `slope_factor × altitude_factor` 的消耗差异，此通道让生物能习得这一物理规律

#### 疲劳 (fatigue)
- **类比**：乳酸堆积
- **触发**：持续高速运动（current_speed 高于阈值超过 N 帧）
- **信号**：负
- **驱动行为**：间歇性休息，避免全力持续冲刺

---

### 体感 / 环境维度

#### 舒适 (comfort)
- **类比**：体温舒适感
- **触发**：nearby_energy 高（heat_factor 低，散热少）
- **信号**：正，散热节省量越多信号越强
- **驱动行为**：主动向高密度生物/能量区聚集，放大群居节能这一物理机制的学习路径

#### 寒冷 (cold_stress)
- **类比**：寒冷不适
- **触发**：heat_factor 接近 1.0（荒野散热大）
- **信号**：负
- **驱动行为**：离开空旷荒野，向密集区移动

#### 地形适应 (terrain_ease)
- **类比**：栖息地偏好
- **触发**：当前高度接近 comfort_h（地形舒适高度带）
- **信号**：正
- **驱动行为**：偏好在舒适高度带活动，形成海拔分层的种群分布

---

### 社会 / 族群维度

#### 安全感 (safety)
- **类比**：催产素（群体归属感）
- **触发**：视野内同族数量超过阈值
- **信号**：正
- **驱动行为**：群居、不孤独游荡

#### 威胁 (threat)
- **类比**：肾上腺素（应激反应）
- **触发**：被咬 / 视野内出现战力显著强于自身的异族
- **信号**：负
- **驱动行为**：逃跑、回避危险个体

#### 跟随奖励 (follow_reward)
- **类比**：从众安全感
- **触发**：follow_level 高且当帧省力（移动消耗低）
- **信号**：正
- **驱动行为**：长期跟随族群，强化"跟随=省力=奖励"的联结

#### 繁殖质量 (mate_quality)
- **类比**：性选择偏好
- **触发**：交配对象基因相似度处于适中区间（非太近导致近交衰退，也非太远无法配对）
- **信号**：正，相似度越接近理想区间信号越强
- **驱动行为**：偏好跨 clan 但同种的伴侣，主动维持遗传多样性

---

### 痛觉 / 伤害维度

#### 痛觉 (pain)
- **类比**：伤害感受器（Nociception）
- **触发**：被咬时按受到的伤害量注入
- **信号**：负，伤害越大信号越强
- **驱动行为**：逃跑、反击、学会回避危险个体

#### 冲击 (impact)
- **类比**：突发性应激
- **触发**：火山/陨石粒子落点附近（半径内）
- **信号**：负，一次性脉冲
- **驱动行为**：学会回避高危区域

---

### 繁殖 / 后代维度

#### 繁殖驱动 (reproductive_urge)
- **类比**：性激素周期
- **触发**：能量充足（超过阈值）且繁殖冷却结束后，持续注入低强度正信号
- **信号**：正（持续低强度）
- **驱动行为**：能量充足时主动寻找伴侣，而非只被动等待神经输出触发

#### 亲代投资 (parental)
- **类比**：哺育本能
- **触发**：子代（parent_id = 自身 id）在视野内且存活
- **信号**：正
- **驱动行为**：保护子代、不远离后代，形成哺育行为

#### 两性优势 (sexual_advantage)
- **类比**：有性生殖的遗传优势
- **触发**：与基因差异度达到阈值的伴侣成功 crossover 繁殖（区别于"自我克隆"式低差异繁殖）
- **信号**：额外正奖励（叠加在 pleasure 之上）
- **驱动行为**：偏好基因多样的伴侣，两性繁殖的进化稳定策略

## 扩展方式

新增一个通道只需三步：

1. **`PhysioState`**（`creature.rs`）：加一个字段，如 `pub pain: f64`
2. **`PhysioGene`**（`genome.rs`）：加对应敏感度，如 `pub pain_sensitivity: f64`，并在 `mutate_physio_gene()` 中加变异逻辑
3. **`world.rs`**：在对应事件发生处写入信号值，如 `creature.physio.pain += damage`

`total_reward()` 和 `apply_physiology()` 无需改动——`total_reward()` 中加一行叠加即可。

## 设计原则

- **负信号不是惩罚机制**，而是反方向的学习驱动——痛觉让生物学会"不做什么"
- **通道间相互独立**，敏感度基因各自演化，允许出现"无痛感"或"极度饥饿敏感"的特化种群
- **不硬编码行为**，所有通道只提供信号，行为由神经网络自行习得；信号强弱、敏感度高低都是演化的对象
- **物理机制优先**：省力、舒适、地形适应等通道的价值在于把已有物理规律（坡度消耗、散热公式）暴露为可学习的信号，而非绕过它们
