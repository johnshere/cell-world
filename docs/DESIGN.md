# Cell World v1.0 - 神经网络涌现系统设计文档

## 一、项目概述

基于神经网络的二维生态演化模拟器，所有生物行为（集群、种群分化、捕食、合作等）都是自然进化的结果，而非预设编程。

### 技术栈

- **语言**：Rust
- **渲染**：egui + eframe
- **哈希**：FxHashMap（rustc-hash）
- **序列化**：serde + serde_json（可选 persistence feature）

### 世界特性

- **无限世界**：没有边界，生物可自由移动
- **动态视窗**：支持拖拽平移、鼠标滚轮缩放（以鼠标位置为中心）
- **火山能量源**：火山定期喷发，陨石随机降落，粒子随时间衰减
- **环境温度**：距火山越近越热，影响代谢和温度流失
- **痕迹点系统**：移动消耗转化为痕迹（能量守恒），可被吸收

---

## 二、设计理念

### 核心原则

1. **真实规则**：引入器官系统、痕迹点、环境温度，使物理规则更贴近真实生态
2. **行为涌现**：所有复杂行为是进化的副产品
3. **开放进化**：神经网络结构和器官基因同时进化（NEAT）

### 什么是预设 vs 涌现

| 类型 | 示例 | 性质 |
|------|------|------|
| 物理约束 | 能量守恒、死亡条件、器官消耗 | 不可避免，类似自然法则 |
| 编程行为 | if 饥饿 then 找食物 | 应避免 |
| 涌现行为 | 集群、捕食、合作、寄生 | 进化的结果 |

---

## 三、物理约束

```
1. 存在消耗：(基础代谢 + 器官消耗) × 年龄倍率 × 环境温度倍率 + 体温逸散
2. 繁殖成本：繁殖时分走 30% 能量给子代
3. 死亡条件：能量 ≤ 0 → 死亡
4. 能量守恒：移动消耗 → 痕迹点能量
```

## 四、器官基因系统

### 器官类型

| 器官 | 消耗(/秒) | 关闭效果 |
|------|-----------|---------|
| 鼻子 | 0.005 | input[0..4] = 0，失去嗅觉 |
| 双眼 | 0.008 | input[5..12] = 0，完全失明，只能靠嗅觉 |
| 嘴巴 | 0.003 | 不能吃/咬/喂（但可以被喂 → 寄生可能） |

### 器官变异

- 变异概率：mutation_rate × 0.1（约1.5%）
- 每次变异随机翻转一个器官的开关
- 交叉时器官从 fitter 方继承
- 器官差异影响相似度：每个不同器官扣 0.05（最多 0.15）

## 五、神经网络设计

### 感知系统（鼻子+双眼）

```
         鼻子(30°半角)
            |
        ====|====
       /    |    \
      / 左眼(120°) 右眼(120°) \
     / heading-60°  heading+60° \
    /                              \
   ○ (生物)
```

- **鼻子**：正前方 30° 半角，强度叠加模型（多目标累加，近处权重大）
- **双眼**：±60° 方向，各 60° 半角（单眼120°视野，合240°），最近距离模型
- **视觉半径**：150 单位

### 输入（16维）

```
鼻子 (5通道) [0..4]:
  [0] 能量粒子强度（叠加）
  [1] 同族强度（叠加）
  [2] 异族强度（叠加）
  [3] 痕迹点强度（叠加）
  [4] 痕迹基因相似度（最强痕迹的 hash 匹配）

左眼 (4通道) [5..8]:
  [5] 能量粒子接近度（最近）
  [6] 同族接近度（最近）
  [7] 异族接近度（最近）
  [8] 痕迹点接近度（最近）

右眼 (4通道) [9..12]:
  [9]  能量粒子接近度
  [10] 同族接近度
  [11] 异族接近度
  [12] 痕迹点接近度

自身状态 (3通道) [13..15]:
  [13] 自身能量 (0~1)
  [14] 体温状态 (0~1, 越冷越高)
  [15] 环境温度 (0~1, 距火山远近)
```

- 器官关闭时对应通道全输出 0，INPUT_SIZE 不变

### 输出（4维，固定）

| 编号 | 功能 | 输出范围 | 说明 |
|------|------|---------|------|
| 0 | 转向角 | tanh(-1~1) | × 2π = 每秒转向弧度 |
| 1 | 速度 | tanh(-1~1) | abs × 50 = 每秒移动距离 |
| 2 | 嘴 | tanh(-1~1) | <-0.1 咬（捕食）；>+0.1 喂（哺育）；需有嘴 |
| 3 | 繁殖 | tanh(-1~1) | >0.2 且能量≥阈值时触发 |

### 激活函数

- 隐藏层 + 输出层：tanh（范围 -1 ~ +1）

## 六、NEAT 算法

### 结构进化

传统神经网络只进化权重，NEAT 同时进化：
- 权重（微调或重置）
- 连接（可新增、可禁用）
- 节点（可新增隐藏层）
- **器官基因**（鼻子/双眼/嘴巴的开关）

### 基因组结构

```rust
struct Genome {
    nodes: Vec<NodeGene>,
    connections: Vec<ConnectionGene>,
    next_node_id: usize,
    organ_genes: OrganGenes,  // v1.0 新增
}

struct OrganGenes {
    nose: bool,   // 鼻子
    eyes: bool,   // 双眼
    mouth: bool,  // 嘴巴
}
```

### 变异类型

| 变异 | 触发概率 | 说明 |
|------|----------|------|
| 权重变异 | 15% 每条连接 | 90% 微调 ±0.5，10% 重置 [-1,1] |
| 新增连接 | 15% | 随机连接两个节点 |
| 新增节点 | 15% | 拆分现有连接，插入隐藏节点 |
| 开关连接 | 15% | 启用/禁用随机连接 |
| 器官变异 | 1.5% | 随机翻转一个器官开关 |

## 七、痕迹点系统

### 数据结构

```rust
struct TrailPoint {
    x: f64, y: f64,
    energy: f64,           // 移动消耗转化的能量（守恒）
    initial_energy: f64,
    genome_hash: u64,      // 创建者基因哈希（种族标识）
    age: f64,
    alive: bool,
}
```

### 生命周期

1. **生成**：生物移动后，移动消耗转化为痕迹点能量
2. **衰减**：`energy *= (1 - trail_decay_rate × dt)`，衰减率 0.03/s（比粒子快）
3. **吸收**：有嘴的生物接触范围内自动吸收
4. **死亡**：能量 < 0.05 时消失

### 感知

- 鼻子可闻到痕迹点（强度叠加 + 基因相似度）
- 双眼可看到痕迹点（最近距离）

## 八、环境温度

### 公式

```
ambient = (1 - dist_to_volcano / volcano_heat_range).clamp(0, 1)
```

### 影响

| 效果 | 公式 | 说明 |
|------|------|------|
| 代谢加成 | × (1 + 0.5 × ambient) | 火山口+50%，边缘正常 |
| 温度流失 | × (1 + (1-ambient) × 1.0) | 火山口无额外流失，边缘+100% |
| 自动回暖 | last_warm_time += cold × ambient × 0.5 × dt | 火山附近自动回暖 |
| 神经输入 | input[15] = ambient | 生物可感知环境温度 |

## 九、交互规则

### 吸收（需有嘴）

- 接触能量粒子：自动吸收，获得剩余能量
- 接触痕迹点：自动吸收

### 咬（捕食，需有嘴）

```
条件：嘴输出 < -0.1，且接触到其他生物
流程：战力比对 → 咬伤量 → 消化效率 = 1.0 - similarity
```

### 喂（哺育，需有嘴）

```
条件：嘴输出 > +0.1，且接触到其他生物
效果：转移 20% 能量，效率 50%，被哺育方回暖 70%
```

### 繁殖

```
条件：繁殖输出 > 0.2 且 能量 ≥ 60
优先有性繁殖（crossover + 变异），无配偶时无性繁殖
子代继承器官基因（从 fitter 方）
```

## 十、渲染

### 器官绘制

| 器官 | 形状 | 位置 | 颜色 |
|------|------|------|------|
| 鼻子 | 线段 | 正前方圆边缘延伸 | 淡蓝 (200,200,255) |
| 左眼 | 白圆+黑瞳 | heading-60° 圆边缘 | 白底黑瞳 |
| 右眼 | 白圆+黑瞳 | heading+60° 圆边缘 | 白底黑瞳 |
| 嘴巴 | 小弧线 | 正前方偏下 | 粉红 (255,100,100) |

仅在基因开启时绘制，缩放较小时跳过。

### 痕迹点绘制

- 半透明小圆点，颜色=种族色(genome_hash)
- alpha = 60 × 能量比
- 半径 = 0.5 × scale

### 火山热辐射圈

- 极淡圆环标识温度范围（800 单位半径）
